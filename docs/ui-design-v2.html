1设计原则 —— 为什么这样设计

一屏看懂「今天」

首页把「当前体重、热量余量、今日任务」压缩成一眼可读的信息层级:渐变 Hero 承载仪式感,白色卡片承载数据密度,避免用户为找一个小数点而翻屏。

拇指触达优先

主操作(保存体重 / 记录一餐 / 记录运动)统一为通栏渐变大按钮,落在拇指自然区;日期切换、餐次选择、Tab 切换都放大到 ≥88rpx 的易点区域。

颜色只表达「意义」

绿=达标/健康(摄入、打卡、已达成),琥珀=提醒/未完成,红=超标/体重上升,蓝=消耗/数据。颜色承载语义而非装饰,色盲友好(均配文字/图形辅助)。

温和但有记忆点

克制使用渐变(按钮、打卡、Hero),几何图形仅出现在头部圆斑与分类圆点,避免「AI 味」过度装饰;字号层级 22/26/30/52rpx 节奏统一。
